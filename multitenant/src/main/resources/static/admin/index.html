                Monitoring dùng để làm gì?
                
- Xem sức khỏe backend, runtime model theo tenant, trạng thái KB và tổng quan purchase requests toàn hệ thống.

                
- Platform admin dùng màn này để vận hành/hỗ trợ, không phải màn xử lý nghiệp vụ hằng ngày của cửa hàng.
